现场守护 ProcessGuard.exe
=========================

双击即可，不用装 Python / Java / .NET。

检测间隔、触发后冷却：均可自定义，单位分钟。

条件类型
--------
1. 进程消失 / 进程存在
2. 网络端口掉线 / 可连通
3. 串口：
   - 消失/掉线（系统里没有该 COM）
   - 存在（系统里有该 COM）
   - 空闲（有 COM，但没有程序占用）← 软件本应占用却变空闲时用这个
   - 非空闲/被占用（有程序正在用该 COM）

推荐：扫码软件“假死但仍在、串口已空闲”
- 条件：串口空闲  COM3   （或 OR 进程消失）
- 动作：先结束残留再打开扫码软件
- 冷却：3 分钟，避免反复拉起

配置文件
--------
C:\Users\当前用户\.process_guard\configs.json

关闭窗口会进入托盘继续检测；托盘右键可退出。
